# Database Schema — 256 Logistics Compliance Hub

All tables use PostgreSQL. UUIDs as primary keys. `created_at` and `updated_at` on every table.

---

## Entity Relationship Overview

```
users
  └─ employees (one user = one employee profile, optional)
       ├─ sponsored_workers (extends employees with sponsor fields)
       ├─ employee_documents (many documents per employee)
       ├─ training_records (one per training type per employee)
       ├─ policy_acknowledgements (one per policy per employee)
       └─ driver_risk_scores (one per driver)

vehicles
  ├─ vehicle_documents (maintenance records)
  ├─ walk_around_checks (daily checks, linked to vehicle + driver)
  ├─ defect_cases (linked to vehicle + driver)
  │    └─ defect_photos
  └─ vor_records (linked to vehicle)

toolbox_talks
  └─ toolbox_talk_assignments (which staff, who signed)

audit_logs (immutable, linked to any entity)
alerts (generated by cron, consumed by dashboard)
compliance_scores (daily snapshot per company)
```

```sql
  'active', 'on_leave', 'suspended', 'terminated'
);

-- Vehicle status
CREATE TYPE vehicle_status AS ENUM (
  'active', 'vor', 'sold', 'hired', 'awaiting_repair'
);

-- Defect severity
CREATE TYPE defect_severity AS ENUM ('minor', 'serious', 'dangerous');

-- Defect status (state machine)
CREATE TYPE defect_status AS ENUM (
  'reported', 'under_review', 'repair_booked', 'repaired', 'signed_off'
);

-- Training status
CREATE TYPE training_status AS ENUM (
  'not_started', 'in_progress', 'completed', 'expired'
);

-- Alert severity
CREATE TYPE alert_severity AS ENUM ('critical', 'warning', 'notice');
```

## Indices Strategy

Performance-critical queries drive index placement:

```sql
-- Dashboard alert feed
CREATE INDEX idx_alerts_severity_resolved ON alerts(severity, is_resolved, created_at);

-- Employee document expiry scanning
CREATE INDEX idx_employee_docs_expiry ON employee_documents(expiry_date) WHERE expiry_date IS NOT NULL;

-- Vehicle PMI and MOT queries
CREATE INDEX idx_vehicles_pmi ON vehicles(next_pmi_date, status);
CREATE INDEX idx_vehicles_mot ON vehicles(mot_expiry_date, status);

-- Daily check lookups (missed check detection)
CREATE INDEX idx_checks_vehicle_date ON walk_around_checks(vehicle_id, check_date);

-- Open defects
CREATE INDEX idx_defects_status ON defect_cases(status, severity, created_at);

-- Audit log lookups
CREATE INDEX idx_audit_entity ON audit_logs(entity_type, entity_id, created_at);
```
